# Aselius Preview App

The Aselius Preview app at `preview.aselius.beunec.com` is the public home for a deliverable you choose to publish. You get a link you can hand to someone who has never signed in to Aselius, and it shows the file exactly as it was produced, on any device.

## At a glance
- **What it is:** Public, shareable pages for deliverables you publish from your Aselius Workspace.
- **Where:** preview.aselius.beunec.com, published from the **Publish** button in the Preview Panel.
- **You get:** Files shown exactly as generated, with a **Download** button for the original.
- **Access:** Code access by default, or **Open**, or **Members only**.
- **Snapshot:** Publishing never changes your original. Later edits stay private until you publish again.

## What shows exactly as generated

| File type | How it appears |
|-----------|----------------|
| **Word and PowerPoint** | Rendered as the pages a real office suite would draw, not extracted text |
| **Excel and CSV** | A grid with the workbook's own fonts, fills, number formats, merges and charts. Not prose about a spreadsheet, and not a PDF of one. |
| **PDF, images, video and audio** | Played or shown from the original file |
| **Saved Rivine Code project** | A file tree and a read-only code viewer |

Every published page has a **Download** button for the original file.

> **Note:** Before a Rivine Code project publishes, it is scanned for secrets. If one is found, publishing is blocked and you are shown the exact file and line.

## Access

| Setting | Who can open it |
|---------|-----------------|
| **Code access** (default) | Anyone with the link you share opens it in one tap. Anyone with only the bare address must enter the code. |
| **Open** | Anyone with the address. No code needed. |
| **Members only** | People in your workspace, opening it from inside Aselius |

- **How code access works:** The access code travels in the link itself, after a `#`. Browsers never send that part of a link to a server.
- **Rotating the code:** Rotate a publication's code and every older link stops working immediately.

## Theme and language

- **Theme:** System, Light or Dark, the same choice as the Aselius web app. Each viewer's choice is remembered, with a switch in the page header.
- **Language:** A switch next to the theme control translates the page into any language our translation service supports.
- **Starting language:** Picked from the visitor's country. The visitor's own choice always wins.
- **Never translated:** Code, file names and product names.

## Publishing from the Workspace

1. Open a deliverable in your Taskspace: a Rivine engine's output or a saved Code project.
2. In the Preview Panel, click **Publish**.
3. Keep the default code access, or set the page to **Open** or **Members only**.
4. Share the link.

Publishing creates a snapshot and never changes the original asset in your workspace. Later edits stay private until you publish again.
