# Messaging channels

Telegram, Discord and WhatsApp can each start and follow a real Rivine engine task on your Aselius account. You get the same engines and the same credits, from inside the chat app you already have open.

## At a glance

- **What it is:** Aselius in Telegram, Discord and WhatsApp, running real Rivine engine tasks.
- **You get:** results in the chat, with a one-tap preview link and the plain file.
- **Safety:** you link a chat from your own account, so nobody can link a chat they do not control.
- **Where:** link it in **Settings → Chat apps** in the Aselius web app.
- **Cost:** available on every plan, spending the same prepaid wallet as the web app.

## Linking a channel

1. Open **Settings → Chat apps** in the Aselius web app and choose Telegram, Discord or WhatsApp.
2. Copy the one-time link or code. It is valid for ten minutes.
3. Send it from your own account in that chat app. Linking always goes in this direction, never the other way around.
4. Once linked, that chat is yours: requests sent there run on your Aselius wallet, and results come back to you there.

## Starting and following a task

1. **Ask.** Send a plain-language request in the linked chat, or use `/task` on Telegram and Discord.
2. **Choose.** The bot replies with a menu: pick the Rivine engine, then its specialty, then confirm.
3. **Follow.** While the task runs, check its status, stop it, or answer a question the engine asks.
4. **Receive.** The result arrives with a one-tap preview link to `preview.aselius.beunec.com` and the plain file, so it opens on any device without an Aselius sign-in.

> **Note:** If you tap an older menu after a newer one was sent, it is refused rather than acted on, so a slow connection can never start the wrong task. Answers are matched to the right turn in the same way, so you can never answer the wrong question.

## Per-channel notes

| Channel | Where results arrive |
| --- | --- |
| Telegram | The same private chat you linked |
| WhatsApp | The same private chat you linked |
| Discord | A direct message to you, never a shared server channel, even if you linked from one |

A task started by messaging appears in your Workspace Taskspace list like any other, with the full step trail the engine took.

## Billing

A task started from a messaging channel spends from the same prepaid wallet as the web app, at the same [engine start floor](/aselius-platform/docs/plans-pricing). Messaging channels are available on every plan, alongside Rivine Browse, Aselius MCP and the Rivine Code CLI.
