# Plans and pricing

Aselius has three plans: Base (free), Pro and Essential. Every plan reaches every Rivine engine at the same start floor from one prepaid wallet, so your balance, not your plan, decides what runs.

## At a glance
- **Plans:** Base free, Pro $20/month, Essential $40/month.
- **Free monthly credits:** 5 on Base, 10 on Pro, 20 on Essential. $1 = 1 credit.
- **Credits:** Never expire. Shared across every Aselius surface from one wallet.
- **Engines:** Every engine on every plan, at the same start floors.
- **Usage fee:** A 20% Rivine Infrastructure fee on top of model provider cost.
- **Plans differ in:** Free credits, storage, daily uploads, support and Essential-only perks.

## Plan overview

| Plan | Price | Best for | What you get (summary) |
|------|-------|----------|------------------------|
| **Base** | **Free** | Trying Aselius and light personal use | Core workspace and messaging, plus every Rivine engine at the same start floors as every plan. Explore Taskspace, upload files and run occasional agentic tasks. |
| **Pro** | **$20 / month** | Specialists and daily agentic work | Every Rivine engine at the same start floors, more storage and uploads, isolated sandboxes, and $10 of free credits every month. |
| **Essential** | **$40 / month** | Researchers and teams at higher volume | The most included credits, the largest storage, priority support and a dedicated account manager. |

> **Note:** No plan unlocks or limits an engine. Every engine has one start floor that is the same on every plan, and the wallet decides what you can run.

## Plans in detail

### Base: free
The full platform: Workspace (Taskspace, Governance, Connector), file management, messaging and teams. Every Rivine engine is reachable at the same start floor as on every other plan. Suited to evaluation and light tasks.

### Pro: $20/month
For people who use Rivine daily:
- **Every engine at the same start floors as every plan.**
- Isolated sandboxes for Rivine Code.
- **$10 of free credits every month.**
- **10 GB** storage and **30 workspace uploads per day**.
- Standard priority support.

### Essential: $40/month
For high-volume research and team workflows:
- **$20 of free credits every month.**
- **30 GB** storage and **40 uploads per day**.
- **24/7 priority support** and a **dedicated account manager**.
- **Observability** (turn cost, latency, and retries for your own runs).
- **CloudHandle customization.**

### CloudHandle customization (Essential only)
Set a custom **display name** and an optional **domain alias** for your public identity on Aselius.
- **Display only:** Your real CloudHandle stays your permanent identity. Permissions and workspace access stay tied to it.
- **Readable name:** Show `Dr. Sarah Chen` instead of `user-84729`.
- **Branded alias:** For example `sarah.your-company.com` for enterprise users.
- **Changes:** Change your display name any time. Domain aliases have a **3-day cooldown** between changes, to protect your account.

## Rivine engine start floors

A start floor is the minimum prepaid balance needed to start a turn on that engine. Floors are the same on every plan: Base, Pro and Essential all draw from the same wallet.

| Engine | Start floor |
|--------|-----------------|
| Rivine TaskForce | $2 |
| Rivine Research | $5 |
| Rivine Code | $10 |
| Rivine Creative | $3 |
| Rivine Cicero | $3 |
| Rivine Confluence | $5 |
| Rivine Browse (extension + desktop) | $2 |
| Rivine Assist | $1 |

Selius needs a balance above $1 to start a conversation. The engine it hands off to then uses its own floor from the table above.

## One wallet everywhere

- **Included on every plan:** Rivine Browse, WhatsApp, Telegram, Discord, Aselius MCP and the Rivine Code CLI. None is a separate purchase.
- **Same wallet:** Each of them spends the same credits as the web app.
- **Shared credits:** Credits work across every surface: Workspace, Rivine Browse, the chat apps, Aselius MCP and the Rivine Code CLI.
- **Visibility:** Turn activity and tool calls stay visible in the Taskspace on every plan.
- **Credit transfers:** Send 1 to 500 credits per transfer to another CloudHandle.
- **Usage fee:** Usage includes a 20% Rivine Infrastructure fee on top of model provider cost.
