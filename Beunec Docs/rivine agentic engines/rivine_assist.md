# Rivine Assist

Rivine Assist is the Aselius engine for small, surgical edits to a document already open in Preview. Add a paragraph, fix a colour or tighten a section without paying for a full engine turn.

## At a glance

- **What it is:** A lightweight editor for one asset on screen in Aselius Workspace.
- **Best for:** Quick fixes and additions after you have reviewed a deliverable.
- **Works with:** Markdown, HTML or code open in the Preview Panel.
- **You get:** Exact, targeted changes, never a rewritten document.
- **Cost:** Needs a prepaid balance of at least $1 to start, on every plan.
- **Limits:** Interactive only. Not schedulable and not available through Aselius MCP.

## What it does

- **Edits one asset on screen.** It works on the Markdown, HTML or code already in your Preview Panel.
- **Changes only what you asked for.** Each change targets an exact passage and is checked against the current content before it is applied.
- **Fails safely.** If an edit no longer matches the document, it fails as a whole instead of half-applying.
- **Looks facts up when needed.** For a fact-dependent edit, Assist can run one round of grounded research and apply the findings.

## What it is not

- **Not a scheduler.** See [Automations](/aselius-platform/docs/automations).
- **Not a full engine turn.** New research, code builds or legal work belong to TaskForce, Research, Code, Cicero, Confluence, Creative or Browse.
- **Not unattended.** It is interactive and scoped to the document you are looking at.

## When to use it

| Use Assist | Use a full engine |
| --- | --- |
| One more section in a finished brief | A new research report from sources |
| A colour or copy tweak in generated HTML | A greenfield app or multi-file build |
| A surgical fix after you reviewed the deliverable | A long build with verification and an independent check |
